# Entwicklungsumgebungen (IDE-Integration)

Das IDE-Plugin-System ermöglicht die automatische Erkennung und Auswahl der passenden Entwicklungsumgebung (IDE) für ein Repository. Das System prüft die Repository-Struktur und wählt automatisch Visual Studio für `.sln`/`.slnx`-Dateien oder Visual Studio Code als universelle Fallback-Lösung. Benutzer können IDE-Plugins aktivieren, deaktivieren und ihre Prioritätsreihenfolge in den Programmeinstellungen konfigurieren.
