# Autonome Aufgaben — Projektleiter-Agent-basierte Automatisierung

Autonome Aufgaben ermöglichen eine vollständig automatisierte Projektentwicklung unter Kontrolle eines Hauptagenten (Projektleiter). Der Projektleiter zerlegt die Gesamtaufgabe eigenständig in Teilaufgaben, erzeugt und verwaltet Unteragenten, orchestriert wiederverwendbare Skills und bereitet Pull Requests vor. Das System bietet umfassende Isolation, Governance-Enforcement und Session-Management zur Gewährleistung von Zuverlässigkeit und Kontrollierbarkeit.
