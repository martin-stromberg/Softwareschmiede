# E2E-Test-Infrastruktur — View-Pattern

Strukturierte Klassenhierarchie für wartbare und leserliche End-to-End-Tests. Das View-Pattern abstrahiert wiederholte UI-Interaktionsmuster über FlaUI und ermöglicht automatische Erkennung der aktuellen Anwendungsansicht anhand charakteristischer UI-Marker.
