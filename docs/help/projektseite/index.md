# Projektseite (GitHub Pages)

Öffentliche, statische Landing-Page der Softwareschmiede unter `https://martin-stromberg.github.io/Softwareschmiede/`. Die Seite stellt die Anwendung mit Zweck, zentralen Features, Screenshots sowie Download- und Dokumentationsverweisen vor und wird automatisch aus dem Repository-Stand von `main` ausgeliefert.

> **Hinweis:** Dies ist Repository-Infrastruktur, kein Feature der Desktopanwendung. Die vollständige Pflege- und Betriebsanleitung (Aktivierung von GitHub Pages, Rollout-Schritte, Fehlerbilder des Deploy-Workflows) steht in [docs/CI_CD.md](../../CI_CD.md), Abschnitt „GitHub Pages".
