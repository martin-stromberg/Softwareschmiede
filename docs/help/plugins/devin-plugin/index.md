# Devin-Plugin

Das Devin-Plugin bindet die lokale Devin CLI als KI-Plugin fuer Entwicklungsautomatisierung ein. Die Softwareschmiede startet den Prozess `devin` im Aufgaben-Arbeitsverzeichnis und zeigt die interaktive Sitzung ueber die vorhandene grafische Terminaloberflaeche mit ConPTY an.
