## Fehlende oder unvollständige Testanforderungen

- [ ] **`CliProcessManagerTests.AktualisiereLaufStatusAsync_WithDisposedScopeFactory_Completes` (`src/Softwareschmiede.Tests/Application/Services/CliProcessManagerTests.cs:106–114`) fehlt in „Betroffene bestehende Tests".** Der Test ruft die private Methode `CliProcessManager.AktualisiereLaufStatusAsync` per Reflection auf (`GetMethod("AktualisiereLaufStatusAsync", NonPublic | Instance)`, Hilfsmethode Z. 116–133). Der Plan entfernt diese Methode ausdrücklich (plan.md „Entfernte Methoden: private `AktualisiereLaufStatusAsync`"). Folge ohne Anpassung: `GetMethod` liefert `null` → `NullReferenceException` bei `method.Invoke` → dauerhaft roter Test. Erforderlich ist entweder die Entfernung/Umbenennung des Tests oder die Umstellung auf den neuen Sicherstellungspfad. Damit verknüpft: Die Shutdown-Race-Abdeckung (disposed `IServiceScopeFactory` wird geschluckt) geht für den neuen Persistenzpfad verloren — ein Äquivalent (z. B. `LaufdatenSicherstellenAsync_WithDisposedScopeFactory_Completes`) fehlt auch in der Neu-Test-Matrix. Empfehlung: Test in „Betroffene bestehende Tests" aufnehmen und ggf. als Sicherstellen-Pendant in „Neue Tests" ergänzen, damit die Shutdown-Race-Abdeckung erhalten bleibt.
