Der Server startet neu

Das Update-Paket wird eingespielt und der Status-Server dabei angehalten. Der Vorgang dauert typischerweise weniger als eine Minute — danach ist der Server unter der gewohnten Adresse wieder erreichbar; eine erneute Anmeldung kann nötig sein. Details zum Verlauf stehen im Update-Protokoll (C:\ProgramData\Softwareschmiede\StatusServer\update-install.log).
